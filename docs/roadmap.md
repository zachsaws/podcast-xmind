# Roadmap

This is a priority list, not a release schedule or a claim that unfinished features exist.

| State | Work | What counts as done |
|---|---|---|
| Shipped | Layered reading, information ledger and structural audit | Inspect the skill, tests and saved examples |
| Shipped | Codex/local Work execution and desktop plugin installation | Actual execution and installed/enabled readback recorded |
| Shipped | Chinese reading and an English rendering of the synthetic demo | Both saved reports are audited against the same source ledger |
| Next to verify | Native desktop Chat invocation | Observe selection in a fresh Chat and execute a real request |
| Next to verify | Clean Claude Code installation | Execute the documented install and reading flow on that host |
| Evaluation priority | Long, multilingual and disputed conversations | Independent human units, held-out inputs, omissions and unsupported additions reported separately |
| Under consideration | Topic-map/native `.xmind` export | Decide from user demand; a real importable file and target-app readback would be required |
| Under consideration | Source-specific acquisition adapters | Demonstrate a recurring retrieval gap and a lawful, maintainable adapter |

Please open an [improvement request](https://github.com/zachsaws/podcast-xmind/issues/new?template=feature.yml) with a concrete input and the result you need. A reproducible missing detail is more useful than an unmeasured quality score.
